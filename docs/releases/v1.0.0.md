## Die erste Version von MorniHosting 🎉

Dein eigenes Minecraft-Hosting zu Hause: Server anlegen, starten, Plugins installieren und Backups machen – alles im Browser, ohne Fachwissen.

### Das ist drin

- **Server:** Java (Vanilla, Paper, Purpur, Fabric, Forge, NeoForge), Velocity und Bedrock, Assistent mit RAM-Empfehlung, Import per ZIP
- **Adresse und Erreichbarkeit:** Adresse zum Kopieren, Prüfung „Von außen erreichbar?“, Hilfe zur Portfreigabe
- **Konsole, Dateien, Einstellungen:** Live-Konsole, Datei-Manager mit Editor und Papierkorb, `server.properties` als Formular, MOTD mit Farbvorschau
- **Marktplatz:** Plugins und Mods aus Modrinth, Hangar, SpigotMC und CurseForge (eigener Schlüssel), Abhängigkeiten automatisch
- **Bedrock-Spieler:** Geyser und Floodgate mit einem Schalter
- **Voice-Chat:** Simple Voice Chat mit einem Schalter – Plugin, UDP-Port und Adresse richten sich selbst ein
- **Backups und Zeitpläne:** per Klick oder geplant, Wiederherstellen mit Sicherheitskopie, Vorwarnung im Spiel-Chat
- **Spieler und Welten:** OP, Kick, Bann, Whitelist; Welten hochladen, wechseln, neu erzeugen
- **Anmelden mit Passkey:** Fingerabdruck, Gesicht oder Geräte-PIN statt Passwort (über HTTPS mit deiner Domain)
- **Admin-Bereich:** Domain eintragen, Panel aktualisieren, Passwörter anderer zurücksetzen
- **NetBird:** einmal verbinden, dann bekommt jeder Server mit seinem Namen eine eigene Adresse wie `minecraft.deine-domain.de` – MorniHosting legt alles in NetBird selbst an
- **Benutzer:** Rollen pro Server, 2FA, API-Schlüssel, Protokoll aller Aktionen, Benachrichtigungen an Discord, Slack und Teams
- **Updates:** Das Panel zeigt neue Versionen an und aktualisiert sich per Knopf; deine Minecraft-Server laufen dabei weiter

### Installieren

Proxmox (in der Shell des Hosts):

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/pmornhart/MorniHosting/main/proxmox/mornihosting.sh)"
```

Debian oder Ubuntu:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/pmornhart/MorniHosting/main/install.sh)"
```
